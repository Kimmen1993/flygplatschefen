# Prototyp 5: Bruksåret 1780–81

**Hypotes:** Masugnen (prototyp 4) var utmanande men "bara en sak att hålla koll på". Ett helt år med tre sammankopplade stationer ger Age of Empires-känslan av att jonglera: masugnen, kolningen (milor i skogsskiften som måste tätas) och hammarsmedjan (som konkurrerar om kol och vatten). Till det kommer årstider, vatten, slädföre, kontrakt och händelser.

**Kör:** https://kimmen1993.github.io/flygplatschefen/prototypes/bruksaret/

**Balanstest (automatiska spelare, ett helt år var):**
- Skicklig (3 kolare, tätar milor i tid, mura om på sommaren, tänder vid snön, styr ugnen): 0 frusna härdar, 3/3 kontrakt, +16 300 daler.
- Slarvig (tätar sällan, sköter ugnen dåligt): 29 av 38 milor brann upp, 0/3 kontrakt, −11 000 daler.
- Stjärnor: 3★ ≥ 14 000, 2★ ≥ 8 000, 1★ > 0. Den skickliga testspelaren reagerar perfekt, vilket ingen människa gör.

**Speltest 1 (Kimm):** "omöjligt att tjäna pengar", "för segt att reagera", "den dör bara utan förvarning", "man fattar inte vad man ska göra".
- Orsak: härden blev full, och slaggen över formorna kylde ugnen till frysning på några timmar, utan tydlig varning. Dessutom kom pengarna först i januari.
- Åtgärder: prognos för temperaturen om ett dygn, masmästarens råd med knappen "Sätt malmsats", masmästaren tappar själv (kan stängas av), snabbare respons (satserna sjunker fortare och blästern verkar direkt), varning och paus första gången det blir kallt, förklaring när härden fryser, mildare ras, lägre löner, 4 000 daler från start och tips om att sälja.
- Nytt test: "nybörjaren" som bara följer rådet får +20 300 daler, 0 frysningar och 3/3 kontrakt. Den skickliga får +18 700. Stjärngränserna höjdes till 3★ ≥ 23 000 och 2★ ≥ 14 000.

**Status:** pågår (väntar på speltest 2).

## Speltest 2 (2026-10-30)
Användaren: "fattar fortfarande inte vad som är grejen – inga förklaringar vad man ska göra, hur, vad som påverkar vad."

Åtgärd:
- **Lärotiden** (21 steg): startar i december med brinnande ugn; stationer låses upp en i taget (masugn → smedja → kolning). Spelaren gör varje sak själv (malmsats → ser ugnen svalna → bläster → masmästarens råd → tappa → sälja → resa mila → täta). Ugnen kan inte frysa under lärotiden.
- **Så hänger det ihop**: kedjan skog/gruva → kolhus → masugn → tackjärn → smedja → kunder → kassa, med läget just nu (grön/gul/röd) och vad som styr varje länk.
- **Att göra nu**: 1–3 viktigaste uppgifterna med skäl, i högerpanelen.

Test: botten går igenom hela lärotiden utan att fastna (≈ 75 s i botten-tempo). Nybörjarbotten som följer masmästaren + "Att göra nu": 3/3 kontrakt, 0 frusna, +17–20 k (2 körningar).
