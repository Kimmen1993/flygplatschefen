# Prototyp 2: Bygg och se

**Hypotes:** Det är roligare och mer beroendeframkallande att *bygga* flygplatsen (taxibanor, gater, tankdepåer) och sedan se trafiken köra själv efter ens design än att klicka på varje plan (prototyp 1, "3d-kansla"). Oförutsägbarhet kommer ur ens egen layout plus ett erbjudande att välja mellan dagarna.

**Bakgrund:** Kimms feedback på prototyp 1 var att grafiken och svårigheten var okej, men att det blev "för mycket samma sak att bara klicka".

**Kör:** https://kimmen1993.github.io/flygplatschefen/prototypes/bygg-och-se/ (mus eller touch).

**Status:** pågår (väntar på speltest).

**Regler i korthet:** rutnät 26×14 med 12 m per ruta. Banan ligger på rad 1, och planen sätter ner i östra änden och rullar västerut. Avfart tidigast 6 rutor in (stora plan 9). Start kräver 7 rutor bana framför planet (stora 11). Plan reserverar ruta för ruta, så två plan kan inte mötas på en enfilig taxibana. Tankbilar kör på taxibanor och servicevägar men väntar på plan. Ett plan som cirklar i 75 s flyger till en annan flygplats.
