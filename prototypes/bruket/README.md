# Prototyp 4: Bruket, blåsningen 1780 (känslotest)

**Hypotes:** Det är engagerande att driva en verklighetstrogen träkolsmasugn under en vintersäsong. Utmaningen kommer från fördröjd återkoppling (satserna tar ungefär 1 dygn ner genom schaktet), störningar ur verkligheten (köld, dålig malm, blidväder, hängningar) och en ekonomi där kolet måste räcka och kontraktet måste levereras.

**Bakgrund:** prototyp 3 (rally) var för lätt ("full gas hela tiden"). Fakta finns i `design/research/bruket-referens.md`.

**Kör:** https://kimmen1993.github.io/flygplatschefen/prototypes/bruket/

**Balanstest (automatiska spelare, en säsong var):**
- "Full gas" (malmsats 1,8, bläster 100 %): 8 frusna härdar, 0 stjärnor.
- "Passiv" (standardinställningar, tappar bara): 3 frusna härdar, 0 stjärnor.
- "Skicklig" (justerar malmsats efter temperaturen, rostar grundligt vid ansats): 0 frusna härdar, 2 stjärnor, nära 3.
